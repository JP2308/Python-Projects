# CS50P & Python Projects

A collection of my work from **Harvard’s CS50P: Introduction to Programming with Python**, along with additional Python scripts I’ve written for practice and exploration.  

## 📘 CS50P Work

This section includes solutions and projects completed as part of the CS50P course. They cover a wide range of Python fundamentals:

- **Conditionals & Loops** – simple programs practicing control flow  
- **Functions** – modular code and problem-solving with reusable functions  
- **Exceptions** – error handling and robustness  
- **Libraries** – using Python’s standard library and external packages  
- **Unit Tests** – testing with `pytest`  
- **File I/O** – reading and writing data from files  
- **Regular Expressions** – pattern matching and string processing  
- **Object-Oriented Programming** – classes, methods, and inheritance  
- **Final Project** – a larger capstone project applying multiple concepts  

Each problem set folder contains the exercises for that week, plus any notes I’ve added.  

## 🐍 Other Python Scripts
